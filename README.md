# 珍珍优质果菜订购系统

本项目由 Cloudflare Pages、Pages Functions 和 D1 数据库组成。

## 本次修复后的验收结果

- 商品数量必须是 1–99 的整数，订单不能为空；下架商品和无效规格不能购买。
- 服务器按商品当前价格及所选规格计算金额，不接受浏览器传来的价格。
- 结算页及订单详情显示商品金额、运费与应付金额。
- 商品金额在数据库中按人民币保存；自取点门槛和配送费按页面标示的港币规则计算，再换算进订单金额。
- 付款凭证限 PNG、JPEG、WebP，最大 1 MB；确认收款后不能再上传。
- 后台订单列表不传输付款图片，查看订单详情时才读取。
- 数据库初始化不再通过公开网址触发。

## 新数据库

安装依赖后，执行 `npm run db:init` 初始化本地 D1，再执行 `npm run db:seed` 导入示例商品。生产数据库需要显式添加 `--remote`，且只能在核对数据库名称后执行。

新数据库还需要先注册一个可信任的管理员账号，再由数据库维护人员将该账号的 `users.is_admin` 设为 `1`。不要提供公开的管理员创建接口。

## 已有数据库升级

先备份生产 D1 数据库。然后在部署新代码前运行：

```sh
npm run db:upgrade -- --remote --dry-run
npm run db:upgrade -- --remote
```

升级程序只补缺少的字段、设置表和自取点表；若自取点表已有数据，不会覆盖现有配置。对新数据库应使用 `db:init`。升级与部署都需要 Cloudflare 授权，代码审查和合并本身不会执行它们。

## 发布前检查

1. 用一件普通商品和一件多规格商品下单，核对前台与后台的金额。
2. 检查自取点未达门槛、已达门槛、送货到家的运费。
3. 确认空订单、负数或超量商品、下架商品被拒绝。
4. 上传付款凭证，后台打开订单详情核对；确认收款后再次上传应被拒绝。
5. 核对后台汇率设置、用户消费统计及按用户查看订单。
