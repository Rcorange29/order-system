# 珍珍优质果菜订购系统

本项目由 Cloudflare Pages、Pages Functions 和 D1 数据库组成。

## 本次修复后的验收结果

- 商品数量必须是 1–99 的整数，订单不能为空；下架商品和无效规格不能购买。
- 服务器按商品当前价格及所选规格计算金额，不接受浏览器传来的价格。
- 自取点订单始终免运费。各服务点已确认收款且待配送的订单累计达到门槛后，统一安排配送；进度不按自然日清零。
- 结算页及订单详情显示商品金额、运费与应付金额。送货到家运费为人民币 30 元。
- 商品金额、自取点门槛和配送费均按人民币保存与计算；选择港币显示时按后台汇率换算供参考，当前默认 1 CNY = 1.2 HKD，后台可调整。
- 已付款待配送的自取订单可申请加人民币 30 元单独配送，或申请取消退款。额外运费由店主收取并在后台确认；退款由店主线下退还后在后台标记。
- 店主可按服务点发布配送公告，在配送前一天告知取货时间。网站公告不会自动发送群消息。
- 付款凭证限 PNG、JPEG、WebP，最大 1 MB；确认收款后不能再上传。
- 后台订单列表不传输付款图片，查看订单详情时才读取。
- 数据库初始化不再通过公开网址触发。

## 新数据库

安装依赖后，执行 `npm run db:init` 初始化本地 D1，再执行 `npm run db:seed` 导入示例商品。生产数据库需要显式添加 `--remote`，且只能在核对数据库名称后执行。

新数据库还需要先注册一个可信任的管理员账号，再由数据库维护人员将该账号的 `users.is_admin` 设为 `1`。不要提供公开的管理员创建接口。

## 已有数据库升级

先备份生产 D1 数据库。然后在部署新代码前运行：

```sh
npm run db:upgrade -- --remote --dry-run
npm run db:upgrade -- --remote
```

升级程序补齐申请、公告和自取点相关数据表，并将服务点运费设置为零；尚未付款的旧自取订单运费也会归零。已收款旧订单的历史运费不会自动改写，应核对是否需要线下退还。对新数据库应使用 `db:init`。升级与部署都需要 Cloudflare 授权，代码审查和合并本身不会执行它们。

## 发布前检查

1. 用一件普通商品和一件多规格商品下单，核对前台与后台的金额。
2. 检查自取点未达门槛、已达门槛时均为零运费，送货到家运费为人民币 30 元。
3. 确认空订单、负数或超量商品、下架商品被拒绝。
4. 上传付款凭证，后台打开订单详情核对；确认收款后再次上传应被拒绝。
5. 核对后台汇率设置、用户消费统计及按用户查看订单。
6. 用测试订单提交单独配送与退款申请，核对线下收取额外运费、线下退款后的后台确认步骤。
7. 发布一条仅指定服务点可见的配送公告，核对顾客首页显示。

## 用户名登录与三语内容（2026-10-17）

顾客用用户名和密码登录，微信 ID、WhatsApp、+852 / +86 手机号与登录身份独立；至少填写一种联系方式。不发送短信验证码，忘记密码由商家核实后重设。

公告、优惠券活动支持商家分别录入简体、繁体及英文内容，未提供的译文回落简体。数据库升级命令、受影响字段、测试数据清理说明及逐屏验收步骤见 [本轮交付说明](docs/plan-a-and-trilingual-delivery.md)。
